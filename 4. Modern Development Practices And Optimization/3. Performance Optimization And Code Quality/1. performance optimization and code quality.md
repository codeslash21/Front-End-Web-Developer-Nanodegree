## ESLint
ESLint is a JavaScript linter that can be integrated with Visual Studio Code and individual projects. Key features of a linter are - error detection, coding style enforcement, best practices, customizability, integratoin with development tools. It’s highly configurable, offering many options for rules to suit your coding style and project needs. To install ESLint, use the following command: `npm init @eslint/config@latest`. This will guide you through a series of prompts to customize the tool and configure the rules ESLint will use to help detect potential issues in your code. After installation, you can further configure ESLint in the `eslint.config.js` file. To run eslint with a specific file `npx eslint src/gallery.js`. Some example rules include:
```
// Example ESLint rules:
"no-var": "error", // Errors when 'var' is used
"no-unused-vars": "error", // Errors for unused variables
"semi": ["error", "always"], // Errors for missing semicolons
"no-console": "warn", // Warns if 'console.log' statements remain
```



## Prettier
Prettier is a code formatter that can be integrated with Visual Studio Code. Primary goal of a code formatter is to enforce a consistent coding style across your codebase and automatically formatting your code. While Prettier doesn’t offer as much customization as linters, it’s a valuable tool for ensuring that your code is clean, consistent, and readable. It can also be used to enforce style preferences across your projects. Unlike ESLint, Prettier doesn’t require a separate configuration file. (Although one can be added if it's preferred) Instead, its options can be added directly to the `package.json` file, making it simple to integrate into your workflow.
```
 "prettier": {
  "semi": true, //Will automatically add 
  "tabWidth": 4, //Will set tab with to 4 spaces
  "trailingComma": "all",
}
```



## SVG
While bundlers can compress images, there’s another image format that can improve performance: **SVGs** (Scalable Vector Graphics). SVGs are images generated using math, making them unique compared to formats like JPEGs and PNGs. SVGs work best for icons, logos, and simple images. However, they may not be ideal for complex images, as these can become large and costly to render. Benefits of SVGs -
- **Scalability:** Unlike JPEGs and PNGs, SVGs can scale infinitely without losing quality.
- **Performance:** SVGs load quickly due to their compact, text-based nature, especially for simple graphics.
