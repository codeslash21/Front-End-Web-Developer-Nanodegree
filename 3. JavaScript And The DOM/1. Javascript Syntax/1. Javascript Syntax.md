## Variable
- Variables can be definied using `var`, `let` and `const`. Variables declared with `var` is `global` scoped. And variables declared with `let` and `const` are blocked scope, these variables cant be used outside of the code block where its declared..
- Variables declared with `const` cant be reassigned. Although array and object declared with `const` can be modified.
- Below is example of modification of array and object
```
const array = [1, 2, 3, 4]
array.push(5)

const object = {
	userName: "Taylor",
	profilePic: "../images/pic.webp",
	status: "paid"
}
object.userName = "Olivia"
```



## Destructuring
### Array
```
const coordinates = [ 30, 14, 25 ]

const x = coordinates[0]
const y = coordinates[1]
const z = coordinates[2]

const [x, y, z] = coordinates
```


### Object
```
const currentUser = {
		userName = "Olivia",
		profilePic = "../images/pic.webp",
		status = "paid"
}

const user = currentUser.userName
const profilePic = currentUser.profilePic
const status = currentUser.status

const {userName, profilePic, status} = currentUser // variable names have to match up with keys in your object
const {coolUserName, profilePic, status} = currentUser
console.log(coolUserName) // output: undefined
```

#### Aliasing
```
const {coolUserName: userName, profilePic, status} = currentUser
console.log(coolUserName) // output: Olivia
```

#### Default Values
```
const currentUser = {
		userName: "MarkG",
		profilePic: "../images/pic.webp",
		status: "paid"

}
const {userName, profilePic,status, isAwesome = 'true'} = currentUser
console.log(isAwesome) // output = true
```



## Template Literals
Template literals are basically string literals that allow you to embed expressions in the string. When you make your string, surround it with backticks instead of single or double quotes. It preserves newlines in your string. 
```
const message = `You have notifications`

const welcome = `${userName},
Welcome back! You have ${notifications.length}
messages waiting for you.`
```



## Function
### Declaration
```
function greet(name) {
	console.log(`Hello, ${name}`)
}
```


### Expression
```
const greet = function (name) {
	console.log(`Hello, ${name}`)
}
```


### Arrow Function
```
const greet = name => console.log(name)
const greet = ( firstName, lastName ) => `Hello, ${firstName} ${lastName}`

const greet = (firstName, lastName ) =>  {
		firstName = firstName.charAt(0).toUpperCase() + firstName.slice(1);
		lastName = lastName.charAt(0).toUpperCase() + lastName.slice(1);
		fullName = `${firstName} ${lastName}`
		return `Hello, ${fullName}`
}
```
- If the arrow function has only one line of code then `{}` is not needed and explicit `return` statement also not needed, value of that expression will be returned automatically. For multi-line function definition we must use `return` explicitly to return any value.
- Arrow functions don’t have their own ‘this’ context. Also, You can’t use arrow functions for constructors.
- Arrow functions can’t be used for object methods, mostly because of lacking a ‘this’ context.
- Arrow functions can only be functional expressions.



## Loop
### For Loop
```
for (let i = 0 , i<array.length, i++) {
}
```

#### for-in loops
`for-in` loops are designed primarily to be used with objects. 
```
const user = {
		userName: "Olivia",
		profilePic: "./image/pic.webp",
		status: "paid"
}

for (const key in user) {
	console.log(user[key])
}
```
If we use this with an array then it will print the indices of all array element. In the following case it will print all the integers in the range `[0,5]`.
```
const names = ["Olivia", "Taylor", "Sabrina", "Harry", "Ed", "Bruno"]
for(const name in names)
    console.log(name);
```
#### for-of loops
`for-of` loops are meant to be used with any iterable object, like arrays, strings, and others. It's not designed to be used with objects like `for-in`.
```
const numbers = [2, 5, 6, 7]
for (const number of numbers) {
	console.log(number)
}
```


### forEach method
`forEach()` is an array method that iterates over each element in an array and performs an action on it. `forEach()` takes a callback function as its argument. `forEach` doesn’t actually return a value. You’re just performing an action. That's called a side-effect. You can affect things in the DOM by doing things like adding an element to a document fragment which will later be rendered, but you’re not getting anything new out of the .forEach() method itself.
```
array.forEach((element, index, array) => { })
```


### map
`map()` returns the result as a new array without affecting the original array. It's really designed to transform your array into something else, like maybe DOM elements. `map()` takes a callback function as argument.
```
array.map((element, index, array) => { })
```



## Spread Operator
A spread operator is a tool you can use to expand any of your arrays and objects into their individual elements. So if you have an array of numbers, it will spread out the array into individual numbers. If you have an array of objects, it will spread out into individual objects. If you have an object, it will spread out the properties into a new object.
```
// Array
const array1 = [1,2,3,4]
const array2 = [5,6,7,8]
const combinedArray = [...array1, ...array2]
console.log(combinedArray)		//output : [1,2,3,4,5,6,7,8]

// Object
const user = {
	name: 'Mark',
	id: '123456'
}
console.log(...user)	//output: Uncaught TypeError: Spread syntax requires ...iterable[Symbol.iterator] to be a function
console.log({...user})	//output: {name: 'Mark', id: '123456’}
```


### Referential Equality
```
const user = {
	name: 'Mark',
	id: '123456'
}

const newUser = user
```
- With a simple declaration like this, newUser actually just holds a reference to the original object in memory. It’s not actually a new object. So if you make any changes to the original user, `user.name = 'Taylor'` those changes would also appear in newUser object.
- **Principle of Immutability** is once an object is created, it should stay the same for its entire lifespan. So that API response you’re saving in an object, should not be modified. In order to satisfy they principle of immutability, create a copy of your data and modify that as needed.
```
const modifiedUser = {...user}
const modifiedUser = {...user, role:'Admin'}
```
- We’re going to make modifiedUser an object and spread our original user into it. This takes each property of our original user object and places it in our new object in a new location in memory. If we need to, we can also add some additional data to the user data by adding another key value pair to the object.
