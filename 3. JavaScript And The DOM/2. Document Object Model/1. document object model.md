## DOM
The DOM is nothing more than an interface to interact with a web page. A web page is written with HTML. Programming languages, like JavaScript, have no way to interact directly with HTML because it’s just a markup language. The browser parses the HTML and converts it into a series of nodes and Objects that look a lot like a family tree. That tree ultimately becomes the Document Object Model. Nodes and elements and everything in the DOM are provided by the browser, not JavaScript.

At each level of the tree, objects inherit the properties and methods of its parents. The browser starts the process by converting HTML tags into Nodes. Those nodes are then converted into Elements. Since these elements start off as nodes, they inherit all the properties of the node. 


### EventTarget Interface
The EventTarget interface is what gives a node or element access to listeners and register events in the browser. It enables nodes and elements to receive and handle events in the browser. Every node implements this EventTarget interface. Since each element inherits from their parent node and nodes implement the EventTarget Interface, every element has access to the EventTarget interface by inheriting it from that node. In DOM not every node is an element. For example, comments in an HTML document are actually rendered in the DOM as nodes, but aren’t elements themselves. But since they’re nodes, they implement the EventTarget Interface. That means, you can interact with comments with JavaScript, but you can’t do much with them.

## Accessing DOM

Notice that even above the `html` is the `document`. `document` is one of the objects the browser creates when it generates the DOM and it references the whole HTML document you’re working with, means the whole object representation of the HTML. Since it’s at the root level of the document, you can get access to all of its children. That means that every element in the DOM is a property of the document object that you can access. If you go into your developer tools and just type `document`, Your response will be entire HTML, just like you see in the Elements tab of your developer tools. Well, technically it looks like HTML, but remember, it’s actually a lot of objects with their own associated properties and methods. So now you can see that just by using the `document` object, you have access to all the elements on the page. Now we can use the DOM API on the document object. DOM API is part of the DOM and includes all the methods we’ll need to modify elements in the DOM, including querySelector, querySelectorAll, getElementById and more.



## querySelector
First get access to the DOM with the `document` object, then use either the `.querySelector()` or `.querySelectorAll()` method on the `document` object. Inside the argument, you’ll use your CSS rules to define the elements you want to select.
```
document.querySelector('navbar')
document.querySelector('#userProfile')
document.querySelector('.class')
document.querySelector("input[name='userName']")
document.querySelector("div.dashboard div.userProfile input[name='userName']")
// target an input for a 'userName' inside a div with a className of 'userProfile' that’s a child of a div with a className of 'dashboard'.
```
- `.querySelector()` only returns 1 element. It will return the first element it finds that matches the argument you give it.
- `.querySelectorAll()` will return all the elements that it finds that matches your query. It returns a **nodeList**. Nodelists have their own `forEach()` method you can use that works exactly the same as a forEach loop. The spread operator can consolidate lists of items into an array, so you can use it to convert your `nodeList` into an array and run your array methods on it.
