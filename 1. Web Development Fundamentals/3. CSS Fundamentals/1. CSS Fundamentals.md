## HTML Class and ID
- The **class** attribute is used to group multiple elements together, enabling the same styles or functionality to apply to all of them. You can assign multiple classes to an element by separating them with spaces, making class highly versatile and reusable.
- The **id** attribute is meant to uniquely identify a single element. It should only appear once per page, as repeating the same id can cause errors or unpredictable results. IDs are ideal for targeting one specific element when unique behavior or styling is required.


### Naming Conventions
There’s no fixed rule for naming class and id values, but consistency is important.
- **Kebab-case**: `button-primary` Common in CSS libraries like Bootstrap and aligns with CSS properties and values.
- **CamelCase**: `buttonPrimary` Often used in JavaScript. Use whichever naming convention fits your workflow, but ensure it's consistent throughout your project.



## Implementing CSS
### Inline Styles
- Declared directly within the style attribute of an HTML tag.
- Styles are written as a single line of CSS, with properties separated by semicolons.
- Inline styles are not reusable, make your HTML cluttered, and violate the DRY principle ("Don't Repeat Yourself"), which encourages reusing code to avoid duplication.
```
<h1 style="color: red; font-size: 24px;">Hello, world!</h1>
```


### Internal CSS
- Written in a `<style>` element within the `<head>` of the HTML document.
- Keeps HTML and CSS somewhat separate by moving styles out of individual tags.
- Useful for small, single-page projects but not scalable for larger websites.
```
<head>
    <style>
        h1 {
            color: red;
            font-size: 24px;
        }
    </style>
</head>
```


### External CSS
- This is not only the preferred method but also considered the general standard for professional web development.
- Styles are written in a separate `.css` file and imported into the HTML document using a `<link>` element.
- Keeps HTML and CSS completely separate, improving readability and maintainability.
- Allows a single stylesheet to be reused across multiple pages for consistency.
- Scalable for large projects and compatible with external libraries like Bootstrap.
- With external CSS, you can link multiple stylesheets to one page, combining custom designs with external resources. The rel attribute indicates the file type (stylesheet for CSS), and the href attribute specifies the file's location. For professional, maintainable, and scalable projects, external CSS is essential.
```
<head>
   <link rel="stylesheet" href="styles.css">
</head>
```

## Common Font Formats
- **TrueType (TTF):** A widely used format that supports both Windows and Mac systems. It allows for scalable fonts, meaning that they can be resized without losing quality. 
- **OpenType (OTF):** An extension of TrueType that supports additional features like ligatures and advanced typographic options.
- **Web Open Font Format (WOFF):** A compressed format specifically designed for use on the web, which helps reduce file size and loading times.
- **Embedded OpenType (EOT):** A format primarily used for embedding fonts in web pages, mainly in Internet Explorer.
