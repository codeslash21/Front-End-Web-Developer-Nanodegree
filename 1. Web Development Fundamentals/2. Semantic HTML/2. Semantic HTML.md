## Importance Of Semantic HTML
While semantic HTML might not always produce immediate visible results, it plays a crucial role in creating high-quality code. There are three main reasons why good semantic practices are important:
- **Code Readability:** Using meaningful tags (e.g., `<section>`, `<article>`) makes your code easier to understand and maintain, saving you time when revisiting or editing it.
- **Search Engine Optimization (SEO):** Proper semantic tags help search engines better interpret and rank your content, which can boost your website’s visibility.
- **Accessibility:** Semantic HTML improves accessibility by assisting technologies like screen readers in interpreting content and enhancing keyboard navigation for users with disabilities.

Here are some other points to consider:
- **Future-Proofing:** Semantic HTML is based on web standards that are less likely to become obsolete, ensuring your site remains compatible with future browsers and technologies.
- **Consistency Across Browsers:** Following semantic HTML practices results in better consistency in how your website appears across different browsers.
- **Easier Collaboration:** When working with a team, semantic HTML makes it easier for others to understand the structure of your code, speeding up collaboration and development.


## Landmark Elements
In web development, it's important to structure your content with meaningful elements that help both users and machines understand the layout of your webpage. Landmark elements, which are special HTML tags, serve as container elements to organize and categorize sections of your page. These elements don’t affect the visual presentation but play a crucial role in making the content more accessible, readable, and easier to navigate.


### Header
The `<header>` element holds introductory content such as logos, titles, or navigation bars. It’s typically used at the top of a page or section.
```
<header>
  <img src="logo.png" alt="Logo">
  <nav>...</nav>
</header>
```


### Footer
The `<footer>` element contains bottom-of-page information, like contact details or copyright notices. It can also be used within smaller sections, like blog posts, to group related controls (e.g., like, comment, share buttons).
```
<footer>
    <button>Like</button>
    <button>Comment</button>
    <button>Share</button>
</footer>
```


### Nav
The `<nav>` element groups navigation links to help users quickly access different parts of the site.
```
<nav>
    <ul>
        <li><a href="/home">Home</a></li>
        <li><a href="/about">About</a></li>
    </ul>
</nav>
```


### Main
The `<main>` element is reserved for the unique content of a page, separating it from content like navigation or headers. There should only be one 'main' element on a page.
```
<main>
    ...page content...
</main>
```


### Section
The `<section>` element is used to group related content, typically with a heading. It's helpful for dividing the page into thematic sections.
```
<section>
    <h2>Info Cards</h2>
    <div>...</div>
</section>
```


### Article
The `<article>` element represents independent content, such as blog posts, news articles, or product descriptions. It can be reused or shared on multiple pages.
```
<article>
    <h2>Product Name</h2>
    <p>Description</p>
    <button>Buy Now</button>
</article>
```


### Figure
The `<figure>` element groups media content such as images, diagrams, or code snippets, along with a caption provided by the <figcaption> element.
```
<figure>
    <img src="image.jpg" alt="Image">
    <figcaption>Image description</figcaption>
</figure>
```


### Aside
The `<aside>` element is used for content that is related to, but not a part of, the main content. It’s perfect for sidebars, related links, or pull quotes.
```
<aside>
    <h2>Recent Posts</h2>
    <ul>...</ul>
</aside>
```



## Other Semantic Elements
### String And Em
`<strong>` is used to indicate that the text is of strong importance or urgency. It typically renders the text in bold but should not be used for generic styling. `<em>` is used to emphasize a word or phrase. It’s typically rendered in italics, indicating stress or change in tone, but should not be confused with marking text as important. Use `<strong>` for important content and `<em>` for emphasizing specific words or phrases to add meaning. Avoid using these elements solely for styling, use appropriate tags like `<span>` or apply styles with CSS instead.
```
<p>Make sure to <strong>submit your application</strong> by Friday.</p>
<p>I'm confident we <em>can</em> finish on time.</p>
```


### Time
The `<time>` element is used for denoting dates and times, which is crucial for SEO (Search Engine Optimization). It allows you to format text for users while including a datetime attribute that helps search engines understand the specific time or date. Here, the date is displayed in a human-readable format, but the `datetime` attribute is what search engines will use for better indexing.
```
<time datetime="2024-12-20">December 20, 2024</time>
```


### Address
The `<address>` element is for contact information, such as emails, physical addresses, or phone numbers. It makes your content more structured and aids accessibility and SEO.
```
<address>
    Contact us at <a href="mailto:info@example.com">info@example.com</a>
</address>
```


### Abbreviation
When writing articles with acronyms or abbreviations, use the <abbr> element to define the full term. This helps search engines and assists readers who may not recognize the abbreviation. The **title** attribute is a standard requirement for `<abbr>` but can be added to any HTML element to provide additional clarification.
```
<p>The <abbr title="World Health Organization">WHO</abbr> is important for global health.</p>
```


### Cite
The <cite> element is for denoting titles of creative works, such as films, books, or songs. This element can also be used in conjunction with a hyperlink to directly link to the media being cited, if it's legally accessible over the internet:
```
<p>A great, early example of cinematography can be seen in
<cite><a href="https://www.loc.gov/item/00694220/?">The Great Train Robbery</a></cite>
which was composed of 14 separate shots.</p>
```


### Quotations
There are two ways to denote quotations: `<blockquote> `for its own dedicated quote element and `<q>` for simple inline quotes.

#### Blockquote
```
<blockquote>
    <p>If you want to be a writer, 
    you must do two things above all others:
    read a lot and write a lot.</p>
    <footer>— Stephen King</footer>
</blockquote>
```

#### Inline Quote
```
<p>
    Stephen King is an acclaimed American author. He referred to books as
    <q cite="https://www.goodreads.com/author/quotes/3389.Stephen_King">a uniquely portable magic</q>.
</p>
```
Note the use of the **cite** attribute, which is entirely different from a `<cite>` element. This attribute is used to cite the actual source of the quote, but it's purely metadata and won't be revealed on the page in any way.



## Semantic Attributes
### Alt
The `alt` attribute is used in image elements to provide an alternate text description. While optional, it’s now considered a required standard, especially for accessibility. It helps screen readers describe images to visually impaired users and displays text if the image fails to load.
```
<img src="logo.png" alt="Company logo">
```


### Lang
The `lang` attribute tells the browser what language the content is in. It is typically added to the `<html>` element, but can also be applied to individual elements to handle multilingual content. This ensures proper pronunciation in screen readers and assists with browser translation features.
```
<p lang="en">
        The French word for cat is <span lang="fr">chat</span>,
        pronounced differently from the English word "chat",
        which means to casually talk with someone.
</p>
```


### For
The `for` attribute in `<label>` tags associates the label with a specific input element, improving accessibility for screen readers.
```
<label for="email">Email:</label>
<input type="email" id="email">
```


### Placeholder
The `placeholder` attribute provides an example or hint within an input field to guide users. This can help with formats, like a phone number, but should not be treated as a replacement for the label element.
```
<input type="tel" placeholder="123-456-7890">
```


### Role
The `role` attribute defines the role of an element, especially useful when custom elements are used that resemble standard HTML elements. This attribute clarifies the element's purpose for accessibility tools. While using native HTML elements like `<button>` is preferred, `role="button"` can clarify the function of a non-native element.
```
<div role="button">Click Me</div>

```



## NOTE
- For verifying sematic html, performance, accessibilty and SEO, we have some tools like - `Lighthouse` on chrome dev tool, `W3C`, `Wave` etc.
- `<meta name="description" content="...">` The `description` meta tag provides a brief summary of the webpage content. Search engines like Google often use the content of this tag as the snippet shown in search results, right below the page title. When someone shares your link on platforms like Facebook, Twitter, or LinkedIn, this description might appear in the preview, making your link more engaging.
-  A **linter** is a piece of software in an IDE that evaluates your code and lets you know if there are any potential errors, bad practices, or coding style inconsistencies. They're implemented to make sure that the code is consistent and follows good practices, especially on team projects. Linters are usually not too picky about semantic HTML, but the 'alt' attribute in images is one that most linters consider mandatory.
-  For validating semantic html we can use online tool such as [W3 Validator](https://validator.w3.org/) or **Lighthouse** validator from Chrome DevTools. There are other options as well, like Wave, IBM Accessibility Checker etc.
