## Document Structure
- The **`<!DOCTYPE html>`** declaration must be at the very top of the file. This tells the browser that the document is written in HTML5, the latest version of HTML. It's a unique tag with an exclamation mark and is written in all capitals. It does not have a closing tag and is a void element.
- **`<html></html>`** The element is the root of the HTML document. All other elements are nested inside this tag. It indicates to the browser that everything within these tags is HTML code. It’s also a good practice to include the lang attribute within the tag to specify the language of the content. For English content, the attribute would look like this: `<html lang="en"></html>`. This helps browsers, search engines, and even translation tools determine the language of the page.
- **`<head></head>`** The element is the section that contains metadata about the page, such as the title and links to external files like CSS and JavaScript. It does not contain visible content for the user.
- **`<body></body>`** The element is where all the visible content of the page is placed. This includes text, images, forms, and other elements that will appear on the webpage.



## HTML Elements
- **Headings:** Headings are used to indicate titles on your page or the beginning of a section. There are six levels of headings, from `<h1>` (most important) to `<h6>` (least important). The main title of your page should always be an `<h1>`, and it should be the only `<h1>` on a page. Also, its not mandatory that `<h1>` will always have biggest font size.
- **List:** The `<li>` tags must always be placed within an ordered or unordered list.
- **Link:** Link is created using the `<a>` tag, which stands for "anchor." We can use `target="_blank"` to open the link in new tab. `<a href="https://www.udacity.com" target="_blank">Visit Udacity</a>`.
- **Div:** `<div>` which stands for division. This element has no functional purpose and is intended as a generic way to compartmentalize your page structure.
- **Span:** `<span>` is used to distinguish a span of text. This tag also has no visual distinction, and is usually used alongside CSS to modify the style of a section of text.

## Form
Forms are essential for interacting with websites, allowing users to submit data for actions such as registration, feedback, or searches. A form begins with the `<form>` element, which houses the various input elements. The form also typically includes a method attribute, which determines how the data will be sent:

- **GET:** Submits data to retrieve information without modifying the website (e.g., search queries). If no method is specified, **GET** is the default.
- **POST:** Submits data that affects the website's backend, such as registering a new account or submitting a comment.

### Form Input Elements
Form inputs are elements that collect user information, such as text fields, checkboxes, date pickers, or dropdown menus. To ensure usability, each input should have an associated label, which indicates its purpose.
- **Labels:** Provide context for input fields and can be declared either as a parent to the input (nested structure) or separately using the for attribute.
- **Association via for and id:** The label element’s for attribute should match the id of the associated input. Each id must be unique within the page.
- **Input name attribute:** Represents the property name of the submitted data and should align with the backend logic. It’s often consistent with the id for clarity.

### Form Validation
HTML input validation ensures that user-submitted data meets specific criteria before being sent to the server. Validation can be implemented using attributes such as:
- **required:** Ensures the field is filled.
- **maxlength / minlength:** Limits the length of text input.
- **type:** Specifies the input format (e.g., email, number).
- **min / max:** Sets numerical or date ranges.
- **pattern:** Validates input using a regular expression.

## Responsive Image
- If we want to show different images based on the screen pixel density, then we can use `srcset` attribute instead of `src` for `img` element. Within `srcset` attributes we can add multiple urls for images, for example `<img srcset="img/img-1.jpg 1x, img/img-2.jpg 2x">`, browser will choose the `img1` for lower pixel density screen and `img2` for higher pixel density screen. Pixel density `2x` means 2 physical pixels render 1 logical pixel for sharpness. Showing different image based on the device's pixel density/ratio is called `density switching`. For density switching browser automatically detects device's DPR (device pixel ratio) and choose the best image for that. Browser handles downloading and rendering of the suitable image, it does not download all the image.
- If we want to show image based on the screen width, then we can use `picture` and `source` element. Within `source` element we can use media query to target a specific device width. If that media query condition is not satisfied, then there will be one fallback `img` element which will be used. Showing different image based on the screen width is called `art direction`.

## DOM
The DOM, or Document Object Model, is a data structure that represents the structure of an HTML document. It’s a hierarchical model that organizes the elements of a webpage like a tree. Each element in the HTML code, such as `<div>`, `<p>`, or `<h1>`, is represented as a node in the DOM tree. These nodes are connected in a parent-child relationship, where one element can contain other elements.

When a browser loads a webpage, it creates the DOM from the HTML code, turning each tag into a node. Each node has properties, such as its attributes and content, and can be manipulated with JavaScript to change the page dynamically. Though you’ll primarily interact with the DOM when you work with JavaScript, it’s important to understand that the DOM is what the browser uses to interpret and display your HTML, and it can differ from the original HTML file.



## Pseudo Element
Pseudo-elements are special HTML element, which does not exist in HTML document. We can select a pseudo-element using `::` and we can select and style that in css. By default pseudo elements are inline element, so if we want to apply padding and margin we have to use `display: inline-block;` style and also we have to specify `content: ""`. There are some important pseudo elements like `before`, `after`, `first-line`, `first-letter`.

If we use `::before` pseudo element then it will be the very first child of its parent and if we use `::after` then it will become very last child of its parent. for eample, if we use `h2::before` then it will become the first child of h2 and will be shown before the main content of h2 and if we use `h2::after` then it will become the last child of h2 and will be shown after the content of h2.



## SVG
For icon, its best practice to use `svg` instead of icon-font, because icon-font more often fail to load and browser show a black square for that. Also, screen reader fails to read icon-font. We can use svg in our webpage in the following way
```
<svg class="search__icon">
  <use xlink:href="img/sprite.svg#icon-magnifying-glass"></use>
</svg>
```
When we download all the icons from the source, then there will be `svg` folder which will have all the icons, but we will not use that because we have to make multiple http call to get all the icons. There will be one icon-sprite file, which will have all the icons, we will use that file to get our icon. In this way we have to make only one http call. Using `xlink:href` will only work in web server. If we want to change the color of the svg icon then there is `fill` property for that.

- `li` element has default display option as `display: list-item`.
- There is one value for `color` property, that is `currentColor`. If we set `color: currentColor` then the color will be the color of parent.
