## Variables
CSS varibales can be local or global scoped. If we want to declare the variables within global scope, then we will declare the variable within `root` pseudoclass. If the varibale is local variable then, it will only be accessed within the elements with that class or any of its children element.
```
:root {
	—-primary-color:#34e8eb;
	—-secondary-color:#6534eb;
}
form {
	background-color: var(--primary-color);
}
```


## Math Functions
- The **`calc()`** function allows you to perform basic math operations like addition, subtraction, multiplication, and division. It’s especially useful for combining values with different units. `width: calc(10px + 10%);`
- **`min()`** selects the smallest value among multiple options, making it ideal for dynamic layouts. `width: min(50%, 300px);`. **`max()`** works similarly but picks the largest value.
- **`clamp()`** adjusts a value responsively within a minimum and maximum range. Can be combined with `min()` and `max()`.
- **`pow()`** raises a base number to a specified power.
- **`sqrt()`** calculates the square root.
- **`abs()`** returns the absolute value of a number.
- **`round()`** rounds a number (to the nearest, up, down, or to-zero).



## Scroll Snap
<img src="https://github.com/user-attachments/assets/046c27fb-54db-42a4-bea8-5c28b7cf0adc" width="300" height="300">

Sometimes, you’ll want to control where users land as they scroll through your content. Scroll snap is a CSS tool that helps guide user focus by defining where their scrolling stops, creating a smoother and more intentional experience.

### Scroll Snap Properties
- **`scroll-snap-type`** property determines the direction and strictness of the snapping action. Here are its possible values:
	- **none**: No snapping occurs.
	- **x**: Snaps only along the horizontal axis.
	- **y**: Snaps only along the vertical axis.
	- **inline**: Snaps along the inline axis (horizontal for most left-to-right languages).
	- **block**: Snaps along the block axis (vertical for most left-to-right languages).
	- **both**: Snaps along both the inline and block axes.
	- **mandatory**: The visual viewport of this scroll container must snap to a snap position if it isn’t currently scrolled.
	- **proximity**: The visual viewport of this scroll container may snap to a snap position if it isn’t currently scrolled.
- **`scroll-padding`**: Sets the scroll padding of the element, which adjusts the snapping area inside the scroll container.
- **`scroll-margin`**: Sets the margin around the snapped element, influencing where it aligns within the scroll container.
- **`scroll-snap-align`**: Specifies the alignment of the snapped item, with values like `start`, `end`, and `center`.



## Backdrop Filter
`backdrop-filter` is to add filter over an image or to make the text more readable over the image. If we want to add modern css properties like `backdrop-filter`, then we need to check, if those are supported by all modern browser or not. For that we can also use `@support`. If the support condition is satisfied then only we will use that style.
```
@support (-webkit-backdrop-filter: blur(10px)) or (backdrop-filter: blur(10px)) {
  -webkit-backdrop-filter: blur(10px);
  backdrop-filter: blur(10px);
  background-color: rgba(#000, .1);
}
```
Here are some commonly used backdrop filters. Each accepts a specific unit:
- **`blur()`**: Adds a blurring effect to the background image. Unit: `px`, `em`, `rem`, `%`
- **`brightness()`**: Adjusts the brightness of the image, making it brighter or darker. Unit: `number` or `%`
- **`contrast()`**: Enhances or reduces the contrast of the image. Unit: `number` or `%`
- **`grayscale()`**: Converts the image colors to grayscale. Unit: `%`
- **`opacity()`**: Adjusts the transparency of the content. Unit: `number` or `%`
- **`drop-shadow(offset-x-axis, offset-y-axis, color)`**: Adds a shadow effect to the content with specified offsets and color. Unit: `px`, `em`, `rem`



## Transitions
Transitions are simple changes in state, often triggered by user interactions such as scrolling or hovering. Transitions broadly apply to state changes, whether through a hover effect or within a looping animation. **Pseudo-classes** are a great way to trigger transition effects. For instance, the :hover pseudo-class can highlight an element, drawing the user’s attention. By using the transition property, we can create smooth effects like easing, making transitions less jarring.


### Transition Properties
- **`transition-property`**: Defines which properties will have the transition effect. Example: `all`, `none`.
- **`transition-duration`**: Specifies the length of time for the transition. Examples: `500ms`, `2s` (in seconds or milliseconds).
- **`transition-timing-function`**: Determines how fast or slow the transition progresses through its duration. Examples: `ease-in-out`, `linear`, `jump-start`.
- **`transition-delay`**: Specifies how long to wait before starting the transition. Examples: `500ms`, `2s` (in seconds or milliseconds).
- **`transition`**: A single property for `transition-property`, `transition-duration`, `transition-timing-function`, `transition-delay`.

```
div:hover {
	background: yellow;
}
div {
	transition: all 5s ease-out 2s;
}
```
- Sometimes we want `transform` property to have trasition effect. But, more than one `transform` property on one declaration block will not work. If we have more than one, then only the last `transform` rule will be applied. So, solution for this is we have to place all the values of `transform` property under one `transform` property, separated by `,` `transform: skewY(2deg) skewX(15deg) scale(1.1);`.



## Animation
Animations are typically driven by events such as page loading, can contain transition effects, and are more complex. Animations can also be triggered by user interactions (e.g., button click). Animation allow for more complex, multi-step effects.


### Animation Properties
- **`animation-duration`**: Specifies how long the animation lasts.
- **`animation-timing-function`**: Determines how fast or slow the animation progresses.
- **`animation-delay`**: Sets how long to wait before the animation starts.
- **`animation-iteration-count`**: Defines the number of times the animation runs.
- **`animation-direction`**: Specifies whether the animation plays forward, backward, or alternates between the two.
- **`animation-fill-mode`**: Controls when the animation styles are applied—before, during, or after the animation.
- **`animation-play-state`**: Allows you to pause or resume an animation.
- **`animation`**: Shorthand, single property for multiple animation values


### Keyframes
`Keyframes` allow you to control what happens during an animation. To create a keyframe, use **@keyframes** followed by the name of the animation. Within the keyframes, `%` are used to specify what happens at different points during the animation. For example, in the following example, we scale an element up and down. At the start (0%) and end (100%) of the animation, the element is at its normal size. At 50%, the element is at its largest size. To tie the keyframes to an element, we use the `animation` property. Alternatively, you can use the `animation-name` property in combination with other animation properties. In this example, we set the `animation-duration` to `10s`, use the ease-in-out` as `animation-timing-function`, and set `animation-iteration-count` to `infinite`.
```
circle {
	animation: breathe 10s ease-in-out infinite;
}
@keyframes breathe {
	0%, 100% {
		transform: translate(-50%, -50%) scale(1);
	}
	50% {
		transform: translate(-50%, -50%) scale(1.5);
	}
}
```


### Background Animation
When multiple elements are stacked, their order is determined by their **z-index** values. Elements with a **lower z-index** sit behind those with a **higher z-index**. We have following two options for background animation: 
- **`position: absolute`** removes the element from the normal document flow and positions it relative to its nearest positioned ancestor. This means the element will not impact or be impacted by other elements. Its placement can be adjusted using the top, right, bottom, and left properties, making it ideal for positioning content as background. This method is faster and easier to implement, making it ideal for simple layouts.
- **`CSS Grids`** is another great alternative for layering content as background elements and applying animations. CSS Grids may be the better choice if you're already using grids for a more complex layout, as it provides more structure and flexibility for applying background animations.

Background animation is different than regular animation in terms of DOM placement. In regualr animation you animate a real DOM element (e.g., `<div>`), it’s part of the page’s content structure. But, for background animation you animate CSS properties like `background-position`, `background-size`, `background-image` or a gradient on an element’s **background paint layer**, no extra content element is added to the DOM (unless you use `::before`/`::after`). Also, one regular animation can push or shift other elements if it’s in the layout flow or you animate layout properties (height, margin, etc.), but background animation doesn’t change layout, so it won’t move siblings around.


### Turning Off Animation
Animations aren't perfect for every user or every device. Animations can impact performance on some devices, so it's a good idea to turn them off for smaller devices such as phones and tablets. Also, many devices provide users with the option to reduce or minimize motion and animation. To help our applications meet these user preferences, we can use a media query to detect a preference for reduced motion. 
```
@media (max-width: 750px), (prefers-reduced-motion: reduce) { 
	.stars { animation: none; } 
}
```



## Parallax Effect
<img src="https://github.com/user-attachments/assets/2f7d589c-cb96-42ad-b158-3b93fce79c58" width="450" height="400">

The parallax effect creates the visual illusion of layers moving at different speeds. In frontend design, this is typically implemented by making a background element appear layered beneath a foreground element, with the background shifting as the user scrolls. This gives a modern and engaging design. Your layout—whether hardcoded in HTML or dynamically generated by JavaScript—should have at least two sibling elements:
- One element serves as the **background**.
- Another element serves as the **foreground** that scrolls over the background.


### Key Rules for the Parallax Effect
- **`height: 100vh;`**: Ensures that both the content and background occupy the full height of the viewport, creating a smooth scrolling effect.
- **`background-attachment: fixed;`**: Keeps the background image fixed in place, so it remains static as the user scrolls.

In the example below, the `<div>` with the class `parallax` will act as the **background** element. This element doesn’t need to be empty. The `<div>` with the class `content` will act as the **foreground** element, which "scrolls over" the background.

```
// index.html
<div class="parallax">
</div>
<div class="content">
          <h2>Hours of Operation</h2>
          <ul>
            <li>Monday–Thursday: 4:00 PM – 11:00 PM</li>
            <li>Friday: 4:00 PM – 12:00 AM</li>
            <li>Saturday: 12:00 PM – 12:00 AM</li>
            <li>Sunday: 12:00 PM – 10:00 PM</li>
          </ul>
</div>
```
```
// style.css
.parallax:first-child {
  background-image: url("./images/food.png");
}
.parallax {
  height: 100vh;
  background-size: cover;
  background-attachment: fixed;
  background-position: center;
}
.content {
  height: 100vh;
  / *Additional styles here* /
}
```
